# Официальные значения `@SuppressWarnings`

Официально `@SuppressWarnings` не имеет «полного списка», зафиксированного в одном месте. Спецификация Java Language Specification (JLS) обязывает компиляторы распознавать только четыре категории, а `javac` дополнительно поддерживает ряд собственных lint-категорий.

## Официально обязательные (JLS)

Эти значения обязаны распознавать все компиляторы Java:

| Значение | Что подавляет |
|---|---|
| `unchecked` | Предупреждения о непроверенных операциях (unchecked operations) |
| `deprecation` | Предупреждения об использовании устаревших (deprecated) элементов |
| `removal` | Предупреждения об использовании API, помеченного для удаления |
| `preview` | Предупреждения об использовании preview-функций языка |
