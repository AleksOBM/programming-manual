# Операции редукции

Сводят поток к единственному значению и завершают его.

- `min()`
- `max()`
- `count()`
- `reduce()`

```java
// 1 - Identity, (a, b) - Accumulator
int evenProduct = myList.stream().reduce(1, (a, b) -> {
	if(b % 2 == О) return а * b; 
	else return a;
});
```

**Identity** – элемент, который является начальным значением операции редукции и результатом по умолчанию, если поток пуст.
**Accumulator** – функция, принимающая два параметра: частичный результат операции редукции и следующий элемент потока.
**Combiner** – функция, используемая для объединения частичного результата операции редукции при распараллеливании редукции или при несоответствии типов аргументов аккумулятора типам реализации аккумулятора.
